# iroh-rooms

The supported Rust SDK for Iroh Rooms. The stable modules are identity, rooms, events, files, and pipes. The online runtime is behind the `experimental` feature.

Versioning, ownership, and publish order are in [docs/sdk-publish.md](https://github.com/kortiene/iroh-room/blob/main/docs/sdk-publish.md). The repository [README.md](https://github.com/kortiene/iroh-room/blob/main/README.md) is the product overview.
