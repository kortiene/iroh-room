# iroh-rooms-core

Deterministic room-event protocol: signing, validation, the membership fold, invite tickets, and the optional local store and sync engine.

Applications should depend on the `iroh-rooms` façade. This crate is part of that closure. Versioning, ownership, and publish order are in [docs/sdk-publish.md](https://github.com/kortiene/iroh-room/blob/main/docs/sdk-publish.md).
