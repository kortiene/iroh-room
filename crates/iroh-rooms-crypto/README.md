# iroh-rooms-crypto

SUITE_V1 content-key primitives used by `iroh-rooms-core`: Ed25519 to X25519 conversion, HKDF-SHA-256 key wrap, and AES-256-GCM.

This crate is part of the `iroh-rooms` SDK closure. Versioning, ownership, and publish order are in [`docs/sdk-publish.md`](../../docs/sdk-publish.md).
